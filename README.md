# self-contained-hacking-lab
setting up my lab

1. I downloaded kali Linux, c++, metasploitable 2 and VirtualBox.
2. I created two machines in VirtualBox: Kali Linux (the attacker), and Metasploitable 2 (the dummy).
3. I tested if they can see each other by pinging Metasploitable 2 on my Kali Linux virtual machine and received the packets.

I chose Metasploitable 2 because it is intended for learning ethical hacking since the system have multiple vulnerabilities. I was torn between the two distros of Kali and Parrot, but ultimately, they are very similar, so I went for Kali as I like the dragon/hydra mascot more. (I am a child at heart).
